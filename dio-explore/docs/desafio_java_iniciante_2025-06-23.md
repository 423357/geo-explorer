# 💻 Desafio DIO — JAVA (Iniciante)

## 📋 Enunciado
Crie um programa em Java que leia uma lista de 5 números inteiros fornecidos pelo usuário
e exiba: o maior número, o menor número, a soma total e a média aritmética.
O programa deve tratar entradas inválidas (letras, caracteres especiais) sem travar.

## ✅ Requisitos
- Usar `Scanner` para leitura dos dados via console
- Armazenar os valores em um `array int[]` de tamanho 5
- Calcular e exibir: maior, menor, soma e média com 2 casas decimais

## 💡 Dica
Use `Integer.MAX_VALUE` e `Integer.MIN_VALUE` como valores iniciais para encontrar
o maior e o menor sem precisar de lógica extra na primeira iteração.

## 📥 Exemplo de Entrada
```
Digite 5 números: 10 3 47 8 22
```

## 📤 Saída Esperada
```
Maior  : 47
Menor  : 3
Soma   : 90
Média  : 18,00
```
