# /desafio

Gere um desafio de código aleatório baseado no nível e tecnologia escolhidos pelo usuário.

## Como usar
```
/desafio <tecnologia> <nível>
```

## Exemplo
```
/desafio Python Intermediário
```

## Níveis válidos
- `Básico`
- `Intermediário`
- `Avançado`

## Instruções

1. Receba a tecnologia e o nível informados pelo usuário
2. Gere um desafio de código criativo, coerente e educativo com base nos parâmetros recebidos
3. Formate o desafio com as seguintes seções:

---

### 🎯 Desafio: [Nome do desafio]

**Tecnologia:** [tecnologia]
**Nível:** [nível]
**XP ao concluir:** [valor aleatório entre 500 e 3000 dependendo do nível]

**📋 Descrição:**
[Descrição clara do problema a ser resolvido]

**📥 Entrada esperada:**
[Descreva o formato da entrada]

**📤 Saída esperada:**
[Descreva o formato da saída]

**💡 Dica:**
[Uma dica sutil para ajudar o usuário sem entregar a solução]

**✅ Critérios de aceite:**
- [ ] O código deve funcionar corretamente
- [ ] O código deve ser legível e bem comentado
- [ ] O código deve seguir as boas práticas da tecnologia escolhida

---

4. Ao final, pergunte ao usuário se deseja ver a solução ou tentar sozinho
