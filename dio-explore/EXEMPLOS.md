## 2️⃣ Exemplos do `/desafio`

### Desafio Python Básico
```
/desafio Python Básico
```

**Saída esperada:**
```
🎯 Desafio: Calculadora de IMC
📊 Nível: Básico | 🏆 XP: 100

📋 Enunciado:
Crie uma função que calcule o IMC (Índice de Massa Corporal)
de uma pessoa e classifique o resultado.

✅ Requisitos:
1. Receber peso (kg) e altura (m) como parâmetros
2. Calcular IMC = peso / (altura²)
3. Retornar a classificação (Abaixo do peso, Normal, Sobrepeso, Obesidade)

💡 Dica: Use if/elif/else para as classificações

📥 Entrada: peso=70, altura=1.75
📤 Saída esperada: "IMC: 22.86 — Normal"
```

---

### Desafio JavaScript Intermediário
```
/desafio JavaScript Intermediário
```

**Saída esperada:**
```
🎯 Desafio: Sistema de Cache com Map
📊 Nível: Intermediário | 🏆 XP: 250

📋 Enunciado:
Implemente um sistema de cache LRU (Least Recently Used)
usando Map do JavaScript.

✅ Requisitos:
1. Capacidade máxima configurável
2. Método get(key) — retorna valor ou null
3. Método set(key, value) — adiciona/atualiza com evicção LRU

💡 Dica: Map em JS mantém ordem de inserção — use isso a seu favor!
```
