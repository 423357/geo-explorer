# DIO Explorer

Submódulo do projeto IBM Bob Lab com trilhas, desafios e certificados da DIO.

## Estrutura

- `commands/` — slash commands do Bob
- `data/` — dados das trilhas em JSON
- `docs/` — documentação e certificados emitidos
- `mcp/` — configurações do servidor MCP
- `src/` — código-fonte auxiliar
